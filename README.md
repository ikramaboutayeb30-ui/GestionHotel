GestionHotel – Application de gestion hôtelière

📌 Présentation du projet

GestionHotel est une application web de gestion hôtelière conçue pour faciliter et centraliser les opérations quotidiennes d'un établissement hôtelier.

Elle permet au personnel de gérer les réservations, les clients, les chambres, les paiements et les utilisateurs à partir d'une interface simple et intuitive.

🎯 Objectifs du projet

Digitaliser les opérations de gestion d'un hôtel.

Faciliter la gestion des réservations et des clients.

Suivre la disponibilité des chambres.

Gérer les paiements et les factures.

Améliorer l'organisation du travail du personnel.

Sécuriser l'accès selon les rôles et les permissions des utilisateurs.

🛠️ Technologies utilisées

Frontend

React.js : création des interfaces utilisateur.

Vite : environnement de développement et outil de construction.

JavaScript : logique de l'application.

Material UI : composants et design de l'interface.

Backend

Node.js : environnement d'exécution JavaScript.

Express.js : création de l'API REST.

Sequelize : ORM pour communiquer avec la base de données.

Base de données

MySQL : stockage et gestion des données.

Outils

Visual Studio Code : environnement de développement.

Git et GitHub : gestion des versions et hébergement du code source.

Postman : test des API (si utilisé).

🏗️ Architecture du projet

Le projet est organisé en deux parties principales :

frontend/ : interface utilisateur développée avec React et Vite.

backend/ : serveur et API développés avec Node.js et Express.

🚀 Installation et lancement

1. Cloner le projet

git clone https://github.com/ikramaboutayeb30-ui/GestionHotel.git
cd GestionHotel

2. Installer les dépendances du Backend

cd backend
npm install

3. Configurer les variables d'environnement

Créer un fichier .env dans le dossier backend en utilisant .env.example comme modèle, puis renseigner les paramètres de connexion à MySQL.

4. Lancer le Backend

npm run dev

5. Installer et lancer le Frontend

Dans un autre terminal :

cd frontend
npm install
npm run dev
